# FireOps Alu2g Simulator
This repository contains a simulator of the Alu2g TCP interface. The simulator is a simple command line tool. It is meant to be used for development purpose only.

## Installation
Just download the binary for your platform and are ready to go.

## Usage
```
Usage of ./fireops-edge-alu2g-simulator:
  -logLvl string
        OFF, FATAL, ERROR, WARNING, INFO, DEBUG, TRACE (default "INFO")
  -maxOperations int
        Maximum of opations contained in a single messeage (default 10)
  -p uint
        TCP-Port where simulated api will be exposed (default 47000)
```
